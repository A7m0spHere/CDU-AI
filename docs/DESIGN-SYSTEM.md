# 设计系统

> 版本：M0 · 与 \`src/styles/\` 中的实现同步维护。  
> 交互与信息密度参考 [VibeHub](https://vibe-hub.org/)：借鉴其白底、蓝色交互色、顶栏搜索与目录式筛选的克制风格，不复制其代码、品牌或页面结构。

## 1. 视觉方向

**清晰、克制、像一个趁手的工具。**

这是一个面向全校的开放学习站，不是科技发布会着陆页。设计要让同学快速找到「我应该从哪里开始」，也能安静地读一篇长文。

- **底色**：纯白页面 + 极浅灰分段（\`#f8f8fa\`），不使用大面积的暖色纸张纹理或装饰渐变。
- **文字**：近黑（\`#18181b\`）为主，灰阶承担元信息层级。
- **交互色**：蓝色（\`#2563eb\`）。链接、主按钮、当前导航、筛选激活态都使用同一套蓝色语义，不再混用大面积绿色与橙色。
- **边框**：1px 浅灰细线承担绝大部分分隔；阴影极轻，仅在浮层、悬停与强调卡片上出现。
- **形状**：8–16px 的克制圆角；卡片不使用斑点、渐变背景和大面积彩色块。
- **字体**：系统中文无衬线栈，不加载网络字体；数字与快捷键使用等宽栈。离线可用、无字体闪烁。
- **作品封面**：保留四套固定色彩的概念插画，作为全站最有表现力的视觉区域；它们是明确标注的「策划示例」，不伪装成真实产品截图。

### 避免的方向

- 紫蓝大渐变、发光边框、玻璃拟态
- 满屏彩色贴纸、旋转卡片、连续弹跳动效
- 把示例作品伪装成真实学生投稿
- 为了「AI 感」而堆叠没有人会用的装饰

## 2. 设计令牌

颜色、字号、间距、圆角、阴影与动效集中在 [\`src/styles/tokens.css\`](src/styles/tokens.css)。组件只使用语义令牌；只有作品插画的印刷色例外。

| \`--bg-soft\` | \`#f8f8fa\` | \`#111113\` | 分段底色 |
| \`--surface\` | \`#ffffff\` | \`#141416\` | 卡片、浮层 |

| \`--ink-soft\` | \`#3f3f46\` | \`#d4d4d8\` | 正文 |

深色主题不是简单反相：背景、卡片、边框、阴影分别取值；品牌蓝会提亮为 \`#60a5fa\`。作品插画在两套主题下保持固定印刷色。

### 字体与字号

- 字体栈：\`Inter → -apple-system → PingFang SC → Microsoft YaHei → sans-serif\`
- 等宽栈：\`SFMono-Regular → Cascadia Code → JetBrains Mono → Consolas\`
- 正文：16px / 1.75；长文页 17px / 1.9。
- 首页展示标题最大约 60px；页头 h1 最大 48px；区块 h2 最大约 31px；卡片标题约 16px。
- 标题使用紧字距与 \`text-wrap: balance\`；关键页头由 \`titleLines\` 显式断行，避免拆开「共建」「维护方式」「找到」等词；移动端保留页头断行，其余标题自然换行。
- 标签/元信息最小 10–12px，但颜色必须达到 AA 对比。

### 间距与容器

- 内容宽度 1200px；长文页正文最宽约 48rem。
- 页面左右留白：\`clamp(1.15rem, 4vw, 2.5rem)\`。
- 区块纵向节奏：\`clamp(3.4rem, 6vw, 5.2rem)\`。
- 常用间距：4 / 8 / 12 / 16 / 24 / 32 / 48px。
- 顶栏固定高度 64px。

### 圆角与阴影

- \`--radius-xs\` 6px、\`--radius-sm\` 8px、\`--radius-md\` 12px、\`--radius-lg\` 16px、\`--radius-xl\` 22px。
- 阴影四档都很轻；卡片默认无阴影，仅靠 1px 边框和留白分层。悬停时才增加极浅阴影与 2px 上移。

## 3. 信息密度与布局

| 断点 | 主要变化 |
| --- | --- |
| ≥ 1280 | 顶栏导航 + 全局搜索框；三列卡片；工具页左侧筛选栏 |
| 1024–1279 | 顶栏收窄，搜索框缩窄；卡片仍三列 |
| ≤ 1020 | 导航收进移动菜单；搜索框变为图标；工具页侧栏变为顶部横向筛选 |
| ≤ 760 | 单列卡片；标题缩小；页头断行保留；筛选控件横向排列 |
| ≤ 480 | 紧凑间距；按钮更接近满宽；隐藏非必要元信息 |

工具页采用 **左筛选栏 + 右卡片网格**：搜索、分类与数量常驻可见，接近 VibeHub 的目录式浏览。其余内容页使用「页头说明 + 内容区」结构，不强行复用侧栏。

学习指南采用目录式 wiki 布局（信息组织参考 [wiki.uestcai.top](https://wiki.uestcai.top/)）：

- 桌面端三栏：左侧固定模块目录（按 3 个阶段分组，每组可折叠；使用浅绿 / 浅杏 / 浅紫三套柔和对比色，当前篇使用同色系高亮），中间为 680px 左右的正文，右侧为「本页内容」目录；
- 指南首页两栏：左侧目录 + 右侧介绍、「从哪里开始」表格、阶段模块清单；
- 1024px 以下隐藏右侧目录；900px 以下收起左侧栏，改为顶部的「目录」折叠面板，组内仍可独立展开；
- 不照搬参考站的颜色与品牌，仅采用其纵向目录、页内锚点和层级阅读结构。

## 4. 交互设计

### 顶栏与全局搜索

- 顶栏：品牌、5 个一级入口、全局搜索、主题切换；移动端收为图标 + 原生 \`<details>\` 菜单。
- 全局搜索使用原生 \`<dialog>\`：
  - 点击搜索框或按 **Ctrl/Cmd + K** 打开；
  - 构建时生成的 \`/search-index.json\` 覆盖页面、8 篇指南、15 个工具、4 个作品示例；
  - 结果按标题、关键词、摘要排序；打开时显示推荐入口；
  - 支持 ↑/↓ 移动、Enter 打开、Esc 关闭；关闭后焦点回到触发按钮。
- 无 JS 时隐藏搜索按钮与主题按钮，核心内容与筛选后的完整条目仍可阅读。

### 导航

- 当前页使用浅蓝背景与蓝色文字，并带 \`aria-current="page"\`。
- 移动菜单使用原生 \`<details>\`，无 JS 可开；JS 只负责点击链接 / 外部区域 / Esc 后关闭。
- 品牌区不额外加 \`aria-label\`，让可见文字成为可访问名称。

### 筛选

- 工具页侧栏有「全部 + 5 个场景」与实时数量；作品页为类别 chips。
- 筛选项使用 \`aria-pressed\`；结果数量通过 \`aria-live="polite"\` 更新。
- 搜索与筛选状态写入 URL 查询参数，可分享与刷新保留；空状态有清除路径。

### 按钮与卡片

- 主操作使用蓝底白字；次操作为白底描边；文字链接只用于低层级跳转。
- 卡片悬停只做 2px 抬升 + 边框加深，不放大、不旋转。
- 整卡可点击时使用 \`<a>\`；包含多个操作的工具卡使用 \`<article>\`，避免嵌套交互。
- 所有外链使用 \`target="_blank"\` + \`rel="noopener noreferrer"\` 与外链图标。

### 主题

- 首屏前内联脚本读取本地偏好或系统偏好，避免闪烁。
- 手动切换后写入 \`localStorage\`；主题按钮同步更新 \`aria-label\`。
- 禁用 JS 时隐藏主题按钮，默认浅色。

## 5. 动效

- 时长：快 140ms / 常规 220ms / 慢 420ms。
- 缓动：\`cubic-bezier(0.22, 1, 0.36, 1)\`，不弹跳。
- 允许：搜索框淡入、卡片悬停抬升、主题和筛选状态过渡、箭头位移。
- 禁止：滚动劫持、视差、自动播放、持续脉冲、列表逐项飞入。
- \`prefers-reduced-motion: reduce\` 时关闭平滑滚动与搜索弹出动画。

## 6. 可访问性

M0 的硬性验收：

- 语义 landmark、跳转链接、唯一 h1、可见焦点环、中文 \`lang\`。
- 浅色与深色主题均用 axe-core 扫描 WCAG A/AA + best-practice：**最终 0 违规**。
- 搜索对话框打开状态下同样扫描通过；对话框使用原生焦点管理。
- 颜色对比达到 AA；状态不只靠颜色，还配文字标签（策划示例 / 筹备中 / 尚未开放）。
- 主要按钮 ≥ 42px，移动菜单 48px，图标按钮 40–44px；正文内联链接保持正常文本流。
- 无 JS 时核心内容完整可读；搜索、主题等增强功能隐藏而非留下失效控件。
- 404 页 \`noindex, follow\`。

## 7. CSS 工程

\`\`\`text
src/styles/
├── tokens.css      设计令牌与主题
├── base.css        reset、排版、布局基础、减少动效
├── components.css  页头/页脚、按钮、卡片基础、Prose、筛选
├── pages.css       首页与各页面区块、响应式骨架
└── vibe.css        视觉/交互收口：紧凑排版、全局搜索、工具侧栏
\`\`\`

约定：

- 新样式先复用 \`components.css\`；页面特有样式放 \`pages.css\`；对既有视觉的收口放 \`vibe.css\`。
- 不引入 CSS 框架；类名采用 BEM 风格的短横线命名。
- 深色主题只通过语义令牌切换。
- 改动视觉后检查 1440 / 1024 / 390 / 320 四个宽度，并重跑 \`npm run verify\` 与 axe。
