# 设计系统

> 状态：M0 现行规范，2026-10-26 更新主题适配约定。实现以 `src/styles/` 和组件为准；历史方案与修订依据见 [设计评审记录](DESIGN-REVIEW.md)。
> 设计基调：清晰的阅读层级、顶栏搜索与目录式筛选；颜色跟随浅色、深色与用户自定义主题，不复制任何第三方项目的代码、品牌或页面结构。

## 1. 视觉方向

**清晰、克制、像一个趁手的工具。**

这是一个面向全校的开放学习站，不是科技发布会着陆页。设计要让同学快速找到「我应该从哪里开始」，也能安静地读一篇长文。

- **底色**：页面、正文和卡片使用对应主题令牌；默认浅色以白色和浅灰为主，深色、预设和自定义主题可改变颜色、渐变与背景图片。
- **文字**：正文、标题和元信息使用各自的语义令牌，随背景保持可读的对比与层级，不在局部固定黑字或白字。
- **交互色**：链接、主按钮、当前导航、筛选激活态共用主题强调色；蓝色只是默认浅色主题的取值。
- **边框**：细线承担绝大部分分隔，颜色跟随主题；阴影仅用于浮层、悬停与强调卡片。
- **形状**：使用已有圆角令牌并兼容自定义设置；内容组件不自行叠加与主题无关的装饰背景。
- **字体**：默认使用系统中文无衬线栈，数字与快捷键使用等宽栈。像素主题使用随站点提供的字体；用户可在本浏览器导入字体文件、填写本机字体名或 https 字体地址。站点预设不依赖外部字体服务。
- **作品封面**：保留四套固定色彩的概念插画，作为全站最有表现力的视觉区域；它们是明确标注的「策划示例」，不伪装成真实产品截图。
- **首页应用展台**：品牌首屏后以三组叠卡展示 AI 的应用可能，每组五张，默认是查资料、做 PPT、写代码。探索组还展示读论文、辅助科研、学知识、练外语；创作组还展示做设计、做图片、做视频、写文案；动手组还展示理数据、操作浏览器、操作专业软件、做自动化。专业软件以 MATLAB 计算与绘图为概念示意。分区只保留主标题，不加标题上方、下方的小字或卡片后的补充说明。卡片内使用本站绘制的概念示意，不是产品截图或真实任务成果，不提供跳转。桌面三列错落排列，手机横向浏览，卡片正文保持一句说明；展台后保留学习、工具、术语入口与简短共建邀请。

### 避免的方向

- 组件自行叠加发光、装饰渐变，破坏用户选定的主题或文字可读性
- 满屏彩色贴纸、旋转卡片、连续弹跳动效
- 把示例作品伪装成真实学生投稿
- 为了「AI 感」而堆叠没有人会用的装饰

## 2. 设计令牌

默认颜色、字号、间距、圆角、阴影与动效定义在 [`src/styles/tokens.css`](../src/styles/tokens.css)，自定义主题由 [`theme-core.ts`](../src/lib/theme-core.ts) 推导相同的语义令牌。页面和组件均使用令牌，包括指南首页；品牌图标与内容插画保留素材本身的颜色，不作为页面固定配色的理由。

### 色彩

| 语义 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| `--bg` | `#ffffff` | `#09090b` | 页面底色 |
| `--bg-soft` | `#f8f8fa` | `#111113` | 分段底色 |
| `--surface` | `#ffffff` | `#141416` | 卡片、浮层 |
| `--surface-muted` | `#f4f4f5` | `#1f1f23` | 标签、次级块、悬停底 |
| `--ink` | `#18181b` | `#fafafa` | 标题与正文强调 |
| `--ink-soft` | `#3f3f46` | `#d4d4d8` | 正文 |
| `--muted` | `#52525b` | `#a1a1aa` | 辅助说明 |
| `--faint` | `#64646d` | `#8b8b94` | 元信息（仍满足 AA 小字对比） |
| `--brand` | `#2563eb` | `#60a5fa` | 主交互色 |
| `--brand-strong` | `#1d4ed8` | `#93c5fd` | 主按钮悬停 |
| `--brand-soft` | `#eff6ff` | `#172554` | 激活背景、浅色强调 |
| `--line` | `#e4e4e7` | `#27272a` | 边框、分隔线 |
| `--line-strong` | `#d4d4d8` | `#3f3f46` | 悬停边框 |
| `--accent` | `#2563eb` | `#60a5fa` | 强调文字 |
| `--sky` | `#0e7490` | `#7dd3fc` | 阶段辅助色 |
| `--sun` / `--sun-soft` | `#a16207` / `#fefce8` | `#fde047` / `#422006` | 「策划示例」标签等注意态 |

深色主题不是简单反相：背景、卡片、边框、阴影分别取值；品牌蓝会提亮为 `#60a5fa`。作品插画在两套主题下保持固定印刷色。

### 字体与字号

- 字体栈：`Inter → -apple-system → PingFang SC → Microsoft YaHei → sans-serif`
- 等宽栈：`SFMono-Regular → Cascadia Code → JetBrains Mono → Consolas`
- 正文：16px / 1.75；长文页 17px / 1.9。
- 首页展示标题最大约 60px；页头 h1 最大 48px；区块 h2 最大约 31px；卡片标题约 16px。
- 标题使用紧字距与 `text-wrap: balance`；关键页头由 `titleLines` 显式断行，避免拆开「共建」「维护方式」「找到」等词；移动端保留页头断行，其余标题自然换行。
- 标签/元信息最小 10–12px，但颜色必须达到 AA 对比。

### 间距与容器

- 内容宽度 1200px；长文页正文最宽约 48rem。
- 页面左右留白：`clamp(1.15rem, 4vw, 2.5rem)`。
- 区块纵向节奏：`clamp(3.4rem, 6vw, 5.2rem)`。
- 常用间距：4 / 8 / 12 / 16 / 24 / 32 / 48px。
- 顶栏固定高度 64px。

### 圆角与阴影

- `--radius-xs` 6px、`--radius-sm` 8px、`--radius-md` 12px、`--radius-lg` 16px、`--radius-xl` 22px。
- 阴影四档都很轻；卡片默认无阴影，仅靠 1px 边框和留白分层。悬停时才增加极浅阴影与 2px 上移。

## 3. 信息密度与布局

| 断点 | 主要变化 |
| --- | --- |
| ≥ 1280 | 顶栏导航 + 全局搜索框；三列卡片；工具页左侧筛选栏 |
| 1024–1279 | 顶栏收窄，搜索框缩窄；卡片仍三列 |
| ≤ 1020 | 导航收进移动菜单；搜索框变为图标；工具页侧栏变为顶部横向筛选 |
| ≤ 760 | 单列卡片；标题缩小；页头断行保留；筛选控件横向排列 |
| ≤ 480 | 紧凑间距；按钮更接近满宽；隐藏非必要元信息 |

工具页采用 **左筛选栏 + 右卡片网格**：搜索、分类与数量常驻可见，属于目录式浏览。手机宽度（≤ 760px）的「全部工具」每页显示 9 个，先搜索和筛选完整目录，再分页；总匹配数与当前展示范围分别显示，翻页后焦点和滚动位置回到结果区，页码可通过 URL、刷新和前进后退恢复。最后一页底部显示「回到第一页」按钮，点击后保留搜索和能力筛选，并回到目录第一页的结果区。搜索、分类或能力条件变化后回到第一页，当前页的空分组隐藏。Agent 与 Harness 恢复国内工具、海外工具、开源工具三组。应用搭建与自动化归开发平台，文档解析与 OCR 独立成栏。AIGC 分为图片、视频、设计、演示文稿、文档与表格、创作工作流；办公与演示栏目撤销，各工具只保留主要用途入口。手机全目录中的更多开源条目直接参与分页；其他视图继续使用「更多开源 Agent 与 Harness」折叠卡（跨整行的 `<details>`，展开后复用卡片网格），搜索或能力筛选时自动展开。禁用 JS 时保留完整目录，打印时展示完整匹配集。工具目录整体不使用滚动 reveal 隐藏，避免长列表无法达到显现比例而留白。术语表采用同一目录骨架：左侧分支树导航，右侧按分类分组的两列词条卡片；移动端折叠为单列。其余内容页使用「页头说明 + 内容区」结构，不强行复用侧栏。

学习指南采用 **Notion 风格文档排版 + 文档中心式画布**：外层浅灰画布，中间白色文档卡；左侧是目录导航，右侧「本页内容」收进文档卡。正文使用中性灰阶、紧凑段落节奏和细线分区，不新增独立文档入口。

学习指南采用目录式 wiki 布局（信息组织参考 [wiki.uestcai.top](https://wiki.uestcai.top/)）：

- 左侧目录按 `guide-nav.ts` 的六个分组组织，每组可折叠；目录分组与 `stage` 的三个学习阶段分别维护，当前篇使用高亮与 `aria-current`；
- 已登记的章节均可进入，尚无正文时标注「待补充」，页面保留标题、短提示与翻页入口，不放大块空白、虚构更新时间或审核信息；
- 指南首页保留左侧目录与右侧正文区域，正文直接导入维护者提供的 `_HOME.md`；背景、正文、标题和链接跟随当前主题，保留加粗的一二级标题与英文术语斜体。首页专用样式只调整排版，不覆盖全局颜色令牌。原介绍、占位提示、目录总览和学习阶段清单不再显示；详情页在正文卡内保留「本页内容」目录；
- 1100px 以下隐藏右侧页内目录；900px 以下收起左侧栏，改为顶部的「目录」折叠面板，组内仍可独立展开；
- 不照搬参考站的颜色与品牌，仅采用其纵向目录、页内锚点和层级阅读结构。

## 4. 交互设计

### 顶栏与全局搜索

- 顶栏：品牌、6 个一级入口、全局搜索、主题切换；移动端收为图标 + 原生 `<details>` 菜单。
- 全局搜索使用原生 `<dialog>`：
  - 点击搜索框或按 **Ctrl/Cmd + K** 打开；
  - 构建时生成的 `/search-index.json` 覆盖页面、指南（含章节锚点）、术语、工具与作品；条目数量随内容集合自动变化，不在文档里写死；
  - 结果按标题、关键词、摘要排序；打开时显示推荐入口；
  - 支持 ↑/↓ 移动、Enter 打开、Esc 关闭；关闭后焦点回到触发按钮。
- 无 JS 时隐藏搜索按钮与主题按钮，核心内容与筛选后的完整条目仍可阅读。

### 导航

- 当前页使用浅蓝背景与蓝色文字，并带 `aria-current="page"`。
- 移动菜单使用原生 `<details>`，无 JS 可开；JS 只负责点击链接 / 外部区域 / Esc 后关闭。
- 品牌区不额外加 `aria-label`，让可见文字成为可访问名称。

### 筛选

- 工具页的场景、能力与计数由 `toolCategories` / `toolCapabilities` 生成；术语分类来自 `glossaryCategories`，作品类别来自内容，不在文档里固定条目数量。
- 筛选项使用 `aria-pressed`；结果数量通过 `aria-live="polite"` 更新。
- 搜索与筛选状态写入 URL 查询参数，可分享与刷新保留；空状态有清除路径。
- 工具页和术语表在桌面侧栏布局（> 1020px）中切换分类、能力、搜索词或清除筛选后，先完成结果布局，再平滑滚动到固定导航下方的结果开头；保留筛选按钮或搜索框焦点，开启「减少动态效果」时直接定位。首次加载、历史恢复、窗口变化和打印不主动重置滚动位置，手机输入不附加此滚动行为。术语表的分支折叠只调整目录展开状态，不触发结果定位。

### 按钮与卡片

- 主操作使用主题强调色与对应按钮文字色；次操作使用表面与边框令牌；文字链接只用于低层级跳转。
- 普通内容卡片悬停只做 2px 抬升 + 边框加深，不放大、不旋转。首页应用叠卡使用小角度的静态叠放，五张卡最多露出两层背板，所有后卡隐藏正文并禁用交互；鼠标横向拖过阈值或点击「换一张」可循环切换本组场景，触摸手势留给横向展台和页面滚动。按钮支持键盘操作，仅当前卡片进入可访问树，无 JS 时保留每组首张展示并隐藏换卡按钮。
- 首页探索区采用左文右卡的双栏：左侧是「开始探索AI」标题与其下的抽象点阵曲面，右侧是三条紧凑入口；900px 以下改回上下堆叠、标题居中。入口行高与字号随栏宽收窄，不再占满整屏。面板、点阵和入口使用全站表面、文字与主题强调色令牌，不固定成参考图的黑白配色。点阵为数学曲面采样的 Canvas，鼠标轻微改变观察角度，静止、离屏或后台不持续重绘；减少动效和触屏保持静态，无 JS 时显示同一曲面的 SVG 回退。三个入口保留流动菜单：桌面悬停时根据进入的上下边缘滑入主题强调色横幅，横幅交替展示入口名称与本站绘制的微型示意图；键盘聚焦同样触发。循环内容至少铺满入口宽度，随组件宽度更新。文字与插画的重复项仅作装饰，不进入可访问名称；整行仍是原生链接。离开入口、滚出视口或切到后台时暂停流动，手机触摸、减少动效与无 JS 时使用静态入口，不引入 React 或 GSAP。
- 指南与作品详情底部显示「最后更新 + 在 GitHub 编辑本页」；有外部依据的模块显示「参考来源」列表。
- 指南首页、正文和占位页底部共用紧凑的「上一章 / 下一章」导航，按左侧目录顺序连接；首尾仅显示可用方向。按钮借鉴胶囊导航的圆形填色与轻微文字、箭头位移，使用网站主题色与对应文字色，悬停和键盘聚焦均有反馈；减少动效时即时变色、取消位移，无 JS 仍可翻页。不引入 React、路由库或 GSAP。
- 整卡可点击时使用 `<a>`；包含多个操作的工具卡使用 `<article>`，避免嵌套交互。
- 所有外链使用 `target="_blank"` + `rel="noopener noreferrer"` 与外链图标。

### 主题

- 首屏前内联脚本读取本地偏好或系统偏好，避免闪烁。
- 顶栏主题按钮提供内置浅色 / 深色、预设与自定义主题；`src/data/themes.ts` 维护预设参数，`src/lib/theme-core.ts` 负责语义令牌推导。
- 预设按浅色、深色和特色分组；特色主题可使用随站点提供的像素贴图、字体或角色图片。素材来源与署名见 [主题素材记录](THEME-ASSETS.md)，第三方图片不改按代码的 MIT 许可发布。
- 字体文件读取与编辑会话绑定；取消、关闭或切换字体风格后，旧读取结果不能覆盖当前草稿。字体拖放不会触发背景图片导入。
- 自定义编辑器支持实时预览、渐变、背景图片及 JSON 导入 / 导出；关闭或取消时停止预览并恢复原主题。自动文字配色按实际对比度选择深浅色，主按钮默认与 hover 均保持可读。
- 代码块文字和注释通过 `theme-code-tokens.mjs` 接入主题变量；切回内置主题时恢复 Shiki 原有语法高亮。
- 手动切换后写入 `localStorage`。自定义主题保存、导入与删除只有在持久化成功后才提交；失败保留原主题并显示可见错误。图片与其他主题共用浏览器存储配额，单图小于 2MiB 仍可能因总容量不足而失败。
- 小屏菜单相对顶栏操作区定位，保证菜单及浅色按钮在视口内；较长菜单可滚动。
- 禁用 JS 时隐藏主题按钮，默认浅色。

## 5. 动效

本节记录当前动效约定；早期方案与调整过程保留在 [设计评审记录](DESIGN-REVIEW.md)。

- 时长：即时 120ms / 快 140ms / 常规 220ms / 慢 420ms / 滚动 reveal 520ms / 首屏进入 560ms。
- 缓动：`cubic-bezier(0.22, 1, 0.36, 1)`，不弹跳；弹簧缓动只用于图标小反馈。
- 允许：首屏 stagger 进入、滚动一次性 reveal、卡片悬停抬升、箭头位移、搜索弹层淡入、主题和筛选状态过渡。
- 禁止：滚动劫持、大块视差、自动播放视频、全局指针替换与大块内容位移。首页引导图的轮播、浮动与瞄准框呼吸仅在该区域生效；触摸与减少动效按组件规则降级。
- CSS 进入与滚动动画只动 `opacity` / `transform`；不监听 scroll 做动画，使用 IntersectionObserver。ASCII 与像素背景使用局部 Canvas 绘制。
- `prefers-reduced-motion: reduce` 时关闭全部动画与 reveal 隐藏，内容立即完整可见；打印样式同样强制可见。

| 场景 | 当前约定 |
| --- | --- |
| 首屏进入与滚动 reveal | 首屏 560ms，stagger 70ms；滚动 reveal 520ms，只触发一次 |
| 卡片与按钮 | 悬停抬升不超过 2px，箭头小幅位移；即时反馈 120–220ms |
| 搜索弹层 | 遮罩淡入、面板小幅上移；原生 dialog 管理焦点，关闭后返回触发按钮 |
| ASCII 品牌字 | 指针附近字符局部驱散，移开后阻尼回位；减少动效下静态且不响应指针 |
| 首页引导图与像素背景 | 模块 hover / focus 点亮连线；装饰瞄准框不替换鼠标；减少动效下停用装饰动画 |
| 首页应用叠卡 | 手动换卡时过渡位置与角度，不自动轮播；减少动效下关闭过渡与前卡倾斜，仍可用按钮换卡 |
| 首页探索菜单 | 悬停 / 聚焦时按上下边缘揭开横幅并横向流动；触屏、减少动效和无 JS 保持静态链接 |
| 首页抽象点阵 | 指针轻微改变曲面观察角度，最多 30fps；静止后停止重绘，减少动效和触屏为静态图 |

CSS 时长来自 `tokens.css`；局部 Canvas 与引导图的参数分别由 `ascii-ai.ts`、`pixel-card.ts`、`hero-network.ts` 与 `target-reticle.ts` 管理。

## 6. 可访问性

M0 的硬性验收：

- 语义 landmark、跳转链接、唯一 h1、可见焦点环、中文 `lang`。
- 浅色与深色主题均用 axe-core 扫描 WCAG A/AA + best-practice：**最终 0 违规**。
- 搜索对话框打开状态下同样扫描通过；对话框使用原生焦点管理。
- 颜色对比达到 AA；状态不只靠颜色，还配文字标签（策划示例 / 筹备中 / 尚未开放）。
- 主要按钮 ≥ 42px，移动菜单 48px，图标按钮 40–44px；正文内联链接保持正常文本流。
- 无 JS 时核心内容完整可读；搜索、主题等增强功能隐藏而非留下失效控件。
- 404 页 `noindex, follow`。

## 7. CSS 工程

```text
src/styles/
├── global.css      全局样式入口与导入顺序
├── tokens.css      设计令牌与主题
├── base.css        reset、排版、布局基础、减少动效
├── components.css  页头/页脚、按钮、卡片基础、Prose、筛选
├── pages.css       跨页面区块与响应式骨架
├── vibe.css        全站导航、紧凑排版与搜索
├── pages-v2.css    共享 PageHeader、元信息、空状态与过渡
├── routes/         首页、工具、作品、活动、关于、社区与错误页的专属规则
├── reading.css     指南与术语共用的阅读布局，保留在共享样式原有顺序中
├── theme-picker.css 色板菜单
├── theme-editor.css 首次编辑或导入主题时加载的对话框与表单
├── home-v2.css     首页 Hero、应用场景叠卡与轻量探索入口
├── notion.css      指南正文、文档画布与页内目录
└── glossary.css    术语分支树、详情模块与交互区块
```

约定：

- 通用组件先复用 `components.css`；已拆分的页面专属规则在 `routes/` 对应文件中维护，不再写入全站样式。`global.css` 保留令牌、基础、共享组件、导航、搜索、目录和阅读布局；`reading.css` 位于 vibe 与 pages-v2 之间，维持阅读页现有覆盖顺序。首页、指南、术语页继续使用 home-v2、notion 与 glossary 的局部样式。编辑器样式以 URL 资产在首次打开时加载，避免 Astro 把动态模块的普通 CSS 导入提升到全站。
- 不引入 CSS 框架；类名采用 BEM 风格的短横线命名。
- 深色主题只通过语义令牌切换。
- 改动视觉后检查 1440 / 1024 / 390 / 320 四个宽度，并重跑 `npm run verify` 与 axe。
