# 站内搜索开发说明

本文说明全站搜索的构建索引和客户端交互。工具页、术语页的列表筛选不使用此索引；共享筛选器与目录交互见[工具目录开发说明](tool-catalog.md)。弹层的视觉和操作要求见[设计系统](../DESIGN-SYSTEM.md#顶栏与全局搜索)。

## 职责与边界

全站搜索在构建时生成 `/search-index.json`，浏览器首次打开弹层时读取，在本页内存中复用。不依赖服务端查询、模型 API、中文分词或跨站检索；内容改变后需要重新构建，浏览器刷新后按需重新获取索引。

## 文件地图

| 入口 | 职责 |

| [`BaseLayout.astro`](../../src/layouts/BaseLayout.astro)、[`global.ts`](../../src/scripts/global.ts) | 共享弹层及全站脚本入口 |

## 数据流与接口

### 构建索引

每项数据包含 `type`、`title`、`description`、`href`、`keywords`；类型包括页面、指南、章节、术语、工具和作品。构建端 `SearchItem` 与客户端 `SearchEntry` 分别定义，修改结构时需同步两端。

| 来源 | 生成方式 |
| --- | --- |
| 固定页面入口 | 在索引端维护标题、摘要、链接和关键词 |
| 指南与作品 | 从内容集合生成条目，再提取二级标题下的正文作为章节候选 |
| 指南首页 | 直接读取 `_HOME.md` 正文和 `getHeadings()`，按同一章节规则处理 |
| 术语 | 使用名称、定义、示例、英文名、别名和分类名称；不把全文自动作为章节索引 |
| 工具 | 使用工具数据、分类、分区名、能力标签等；结果指向带名称搜索词的工具页 |

章节以 Markdown 中的 `##` 切分，按顺序对应 Astro 实际渲染结果中的二级标题 slug。只收录有锚点且归一化正文至少 20 个字符的章节；标题之前的正文不单独生成章节。新增标题处理规则时，必须同时检查正文切分与渲染锚点是否仍一一对应。

只有已进入内容集合的指南文章参与索引；目录中尚无 Markdown 的占位章节不计作文章，也不自动进入搜索。不要手工编辑 `dist/` 中的 JSON。

### 加载与失败恢复

打开弹层后，`loadSearchIndex` 首次请求 JSON；`searchRequest` 合并正在进行的请求，成功结果保存在 `searchEntries`。关闭弹层不会中断请求，完成时只在弹层仍打开时刷新结果。

请求失败显示状态和重试按钮，并在结束后释放请求状态。重新打开弹层或点击重试都可再次请求；成功后在当前页面复用索引。重试时把焦点放回输入框，不重建整个弹层。

### 匹配、展示与操作

- 输入转为小写、合并空白并去除首尾空白；在标题、摘要、关键词和类型的组合文本中做子串匹配，不做多词拆分或语义检索。
- 匹配后按标题命中 3 分、关键词 2 分、摘要 1 分相加排序，最多展示前 10 项；状态区报告完整匹配总数及截断提示。空输入显示前 7 个页面入口。
- 结果通过 DOM 节点和 `textContent` 创建，不把索引文字作为 HTML 注入。空结果提供缩短关键词的提示。
- `compositionstart` / `compositionend` 记录输入法状态；输入框和全局快捷键在组合输入期间不处理导航键，避免 Enter 选字误打开结果。
- ↑/↓ 在输入框与结果之间移动，Enter 打开结果，Esc 或关闭操作关闭弹层。打开前记录焦点，关闭后恢复；状态文字通过 `aria-live` 播报。减少动效时直接关闭，否则完成短暂关闭动效。

## 必须保持的行为

- 所有结果链接及章节锚点与实际页面一致，空集合和指南首页也能处理。
- 工具分类、分区名称与别名从已有数据生成，不在搜索脚本另写一份目录。
- 加载中、失败、空结果和正常结果有不同状态；一次失败不能阻断后续重试。
- 匹配总数与展示上限分开，不能把“前 10 项”当作全部结果。
- 输入法保护、键盘路径和焦点恢复保持有效；无 JS 时共享布局隐藏搜索入口，页面内容仍可阅读。

## 常见修改路径

| 修改 | 需要核对的入口 |
| --- | --- |
| 增加索引字段或内容类型 | 构建端条目生成 → 客户端接口/匹配/展示 → 索引覆盖测试；确认链接与无内容时行为 |
| 调整章节提取 | `splitSections`、`appendBodySections` 与 Astro 渲染标题；核对重复标题、短章节及指南首页 |
| 调整匹配或排序 | `search.ts` 的归一化、匹配和得分；核对中文、别名、总数与展示上限 |
| 调整弹层 | `SearchDialog.astro`、脚本选择器与样式；核对输入法、键盘、焦点、重试和手机宽度 |
| 增加工具搜索信息 | 同时检查索引端和 `ToolCard.astro`，全站搜索与列表搜索各自生成可搜索文本 |

## 验证与排障

命令与环境设置统一见[维护说明](../MAINTAINING.md#验证入口)。索引或页面脚本变更运行 `npm run verify`；交互变更在当前构建上补充 `npm run test:browser`。

| 证据入口 | 检查内容 |
| --- | --- |
| [`site.test.mjs`](../../tests/site.test.mjs) | 指南/页面/术语/工具覆盖、章节文本与锚点、工具别名/技术类型/能力关键词 |
| [`theme.browser.test.mjs`](../../tests/theme.browser.test.mjs) | 中文输入法、键盘打开章节、匹配总数与截断、手机空结果、失败重试及成功后复用 |

- 内容搜不到：先确认当前源码已构建、条目是否属于索引范围，再核对关键词和章节长度门槛。
- 结果跳转不到章节：对照实际渲染 slug 与正文切分顺序，不手工猜测中文锚点。
- 修改后仍出现旧结果：区分本页内存中的旧索引、网络缓存和旧构建；内容缓存排查按维护说明处理。索引响应声明一小时缓存，实际托管缓存行为需另行核实。
