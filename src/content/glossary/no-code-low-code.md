## 是什么

无代码/低代码是用可视化配置搭应用：无代码几乎不写代码，低代码在关键处补少量脚本。

## 什么时候会遇到

做报名表、审批流、数据看板时；平台宣传「拖拽即可上线」。

## 和 AI 的关系

AI 让这类平台更会「听懂需求」，但平台能力有上限，复杂逻辑仍会撞墙；数据也存放在平台方。
