## 一句话说清

词元（token）是模型识别文本的**最小单位**，也是计费单位。按官方文档的说法，一个词、一个数字，甚至一个标点都可能算一个词元。你看到的「上下文长度 1M」「每 1M tokens 多少钱」，说的都是它。

## 打个比方

可以把它想成快递的计费重：你寄的是衣服（文字），快递公司按体积重（词元）收费。衣服可大可小，词元也可长可短——常见英文单词往往是一个词元，罕见词、长数字、生僻字会被切成几块。

所以「这段话多少词元」不能靠数字数猜出来，要用官方提供的分词工具，或直接看接口返回的用量。

## 它是怎么运作的

1. 你的文字先被**分词器**（tokenizer）切成一串词元；
2. 每个词元对应词表里的一个编号，模型实际处理的是这串编号；
3. 模型输出时反过来：先给出编号序列，再还原成文字。

三个常见指标都由词元计算：

| 指标 | 含义 |
| --- | --- |
| 输入词元 | 你发过去的提示词、粘贴的文档、上传文件解析出的文字 |
| 输出词元 | 模型生成的回答 |
| 上下文长度 | 一次请求里模型能同时看到的上限（输入 + 输出） |

## 你会碰到它的场景

- **文档读不完**：材料超出上下文长度时，工具会截断或直接报错。此时不是模型变笨，而是文字被切掉了。
- **费用算不清**：API 按输入、输出词元分别计价，长文档任务通常是输入词元占大头。
- **回答被截断**：单次输出另有上限（DeepSeek API 文档当前标注为最大 384K，随模型调整，以官网为准）。
- **中英文差多少**：DeepSeek 官方文档给的换算口径是「1 个英文字符 ≈ 0.3 词元，1 个中文字符 ≈ 0.6 词元」——**同样字符数下，中文大约是英文的两倍**。但「表达同一个意思」要花多少词元，取决于具体句子，只能实测。
- **换模型要重新数**：不同模型的分词器不同。Anthropic 文档提到，其新分词器下同样的输入大约多出 30% 的词元。跨模型套用旧数字会算错。

## 常见误解

- **「一个词元就是一个字」**：不对。官方口径是一个词、一个数字甚至一个标点都可能是一个词元，中文也可能是半个字或几个字合成一个。
- **「Token 就是登录令牌」**：不是同一个概念。登录凭证也常被叫 token，那是鉴权用的字符串，与这里的计费单位无关。
- **「词元数 = 字数 × 固定系数」**：只能粗估。换算比例随模型、语言和内容变化，正式统计请用官方工具。
- **「窗口够大就不用管」**：窗口越大，越容易把无关材料一次性塞进去，重点反而被稀释，取舍仍然要做。
